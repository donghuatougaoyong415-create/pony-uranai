# ちびポニ占い

ミニチュアポニーがモチーフの、毎日自動で更新される12星座ランキング占いサイトです。

## しくみ
- 日本時間の日付をシード（種）にして、順位・運勢文・ラッキーアイテムなどをブラウザ上で組み合わせて作ります。
- 毎日0:00（JST）に自動で切り替わります。**サーバー・API・毎日の作業は不要**で、費用はゼロです。
- 同じ日なら誰が見ても同じ結果になります（シェアしても内容が一致します）。
- 過去30日分は「‹」ボタンでさかのぼれます。未来の日付は見られません。

## ファイル
| ファイル | 役割 |
|---|---|
| index.html | ページ本体 |
| style.css | デザイン（ダークモード対応） |
| app.js | 占いの生成ロジック |
| img/ | ポニー12頭のイラスト（Geminiで生成、背景を透過したWebP。ファイル名は星座のID） |
| ogp.png | SNSでシェアされたときの画像 |
| favicon.png / apple-touch-icon.png | アイコン |

## GitHub Pages で公開する手順（約5分）
1. https://github.com にログインし、右上「+」→「New repository」。
   名前を `pony-uranai`、**Public** にして「Create repository」。
2. 作成直後の画面で「uploading an existing file」をクリック。
   このフォルダの中身（index.html など全ファイル。フォルダごとではなく中身）をドラッグ＆ドロップ →「Commit changes」。
3. リポジトリの「Settings」→ 左メニュー「Pages」。
   「Branch」を `main`、フォルダ `/ (root)` にして「Save」。
4. 1〜2分待つと `https://（あなたのユーザー名）.github.io/pony-uranai/` で公開されます。
5. **公開後に1か所だけ修正**：index.html の `YOUR-NAME` を自分のユーザー名に置き換えてください（2か所）。
   GitHub上でファイルを開き、鉛筆アイコンから編集できます。これでXなどでシェアしたとき画像が出ます。

## カスタマイズのしかた（app.js）
- `MSG`：運勢メッセージ。top＝1〜3位、mid＝4〜8位、low＝9〜12位。**各グループの文を増やすほど、毎日のバリエーションが増えます**（mid は最低5個、low は最低4個必要）。
- `ITEMS` / `COLORS` / `PLACES` / `PONY_TALK`：ラッキーアイテムなどの候補。自由に追加OK。
- `SIGNS` の `pony`：各星座の担当ポニーの名前・毛色・性格。
- イラストを差し替えるときは `img/` の同じ名前のファイルを上書きします（横480px前後、背景透過のWebPかPNG推奨）。

## 公開後のおすすめ
- **独自ドメイン**：Settings → Pages → Custom domain で設定できます（ドメイン代のみ）。
- **アクセス解析**：Google Analytics などのタグを index.html の `</head>` の直前に貼ります。
- **広告**：Google AdSense は審査に「独自のコンテンツ量」が求められるため、ポニーの紹介ページや星座の解説ページを足しておくと通りやすくなります。
- **集客**：毎朝Xに「今日の1位」を投稿すると定着しやすいです（予約投稿ツールで自動化も可能）。
